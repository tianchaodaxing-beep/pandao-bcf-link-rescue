Installation and full documentation ↗

Install from the project source
python -m pip install .
Recover directly from real IFC files
bcf-link-rescue repair old.ifc new.ifc issues.bcfzip --out review-draft
Or export inventories for this browser
bcf-link-rescue inspect-model old.ifc --out old.inventory.json
bcf-link-rescue inspect-model new.ifc --out new.inventory.json

Focused on one problem.

SupportedBCF 2.1 component references in Selection, Visibility exceptions and Coloring; exported inventories from IFC2X3 and IFC4; exact Tags; unchanged normalized local placements.

Outside this tool's scopeFull BIM validation, camera repair, clash detection, Revit linked-model export fixes, fuzzy identity guesses and geometry equivalence. Review all output in your own model viewer.
